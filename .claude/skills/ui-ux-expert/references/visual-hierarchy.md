# Visual Hierarchy — 시각적 계층 원칙

> 출처: Material Design 3, Carbon Design, Ant Design, Nielsen Norman

## 정보 계층 3단계

| Level | 대상 | 방법 | 예시 |
|-------|------|------|------|
| L1 Structure | 대영역 구분 | 배경색/border/크기 차이 | 모달 3열 각 열 |
| L2 Category | 영역 내 그룹 | 섹션 헤더 + 구분선 | "계좌 이체" vs "카드 결제" |
| L3 Item | 개별 데이터 | 행/셀/체크박스 | 개별 계좌, 카드 |

## 시각적 무게 배분

### 다열 레이아웃
```
주요 영역: 전체 너비의 50% 이상 (1fr)
보조 영역: 고정폭으로 최소화 (px)
```
- 3열 중 가장 중요한 열이 가장 넓어야 함
- 보조 열 2개 합계 < 주요 열 너비

### 크기로 중요도 표현
- 가장 중요한 영역 = 가장 넓은 공간
- 제목 계층: `text-lg` > `text-sm` > `text-xs`
- 라벨 계층: `font-semibold` > `font-medium` > `font-normal`

### 색상으로 주목도 조절
| 수준 | 스타일 | 용도 |
|------|--------|------|
| 높음 | indigo-600, 진한 배경 | Primary 액션, 선택 상태 |
| 중간 | gray-700 텍스트 | 일반 콘텐츠 |
| 낮음 | gray-400 텍스트 | 보조 정보, 힌트 |
| 비활성 | opacity-50 | 조작 불가 영역 |

## 읽기 패턴

### F-패턴 (목록/테이블)
- 상단 좌→우 스캔 → 좌측 위→아래 스캔 → 관심 항목에서 우측 이동
- → **가장 중요한 정보를 좌측 상단에**

### Z-패턴 (폼/설정)
- 좌상 → 우상 → 좌하 → 우하
- → **2열 폼: 좌→우, 위→아래 순서**

## 상태 표현 (Ant Design 참고)

### 선택 상태
| 상태 | 스타일 |
|------|--------|
| 미선택 | `bg-white border-gray-200` |
| 선택 | `bg-indigo-50/30 border-indigo-200` |
| 포커스 | `border-indigo-500 shadow-sm` |
| 호버 | `hover:bg-gray-50` 또는 `hover:border-gray-300` |

### 활성/비활성
| 상태 | 스타일 |
|------|--------|
| 활성 | 기본 |
| 비활성 | `opacity-50 pointer-events-none` |
| 부분 비활성 | `opacity-70` (보이지만 조작 불가) |

### 데이터 유무
| 상태 | 스타일 |
|------|--------|
| 있음 | 정상 표시 |
| 없음 | `text-gray-300` + "없음" 또는 "—" |
| 로딩 | 스피너 또는 스켈레톤 |

## 그루핑 전략 (Carbon Design 참고)

### 논리적 그루핑 우선
```
✓ [메뉴 권한] [비즈니스] [계좌·거래] ← 설정 대상별
✗ [체크박스들] [텍스트들] [버튼들]    ← 컨트롤 타입별 (의미 없음)
```

### 헤더로 그룹 명시
- 각 그룹: `text-xs font-semibold text-gray-700` 헤더
- 배경: `bg-gray-50 border-b`
- 액션(전체선택 등)은 헤더 우측

### 간격으로 그루핑
- 관련: `gap-1` ~ `gap-2` (밀착)
- 비관련: `gap-4` 또는 `border-b` (분리)
- 독립: `border` + `rounded-lg` + `p-3` (격리)
